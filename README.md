# 제조AI — 제조 AI 솔루션 인턴십 교육 자료

제조 현장의 문제를 ISA-95 계층과 제조 시스템(ERP·SCM·PLM·MES·QMS·CMMS·WMS·제어계층) 관점으로 분석하는 12시간 과정의 교재·요약·스터디 노트 모음입니다.

## 폴더 구조

```
.
├── 제조AI-교재/
│   ├── 제조AI-교재-단일.md      # 교재 전문 (이미지 내장, 옵시디언용)
│   ├── 제조AI-요약.md           # 12장 요약본
│   ├── 제조AI-교재-웹.html      # 교재 웹 버전 (브라우저 열람용)
│   ├── 스터디/                  # 영역별 학습 노트 16개 (00~15)
│   ├── 용어정리/                # 용어 해설 39개 (풀이·예시·혼동 주의)
│   └── 원본자료/
│       ├── 강의교재-원본.docx   # 원본 교재
│       └── 교재-이미지/         # 교재 삽입 이미지 16개
├── isa-95.html                  # ISA-95 계층구조 단독 정리 (HTML)
├── isa-95.md                    # ISA-95 계층구조 단독 정리 (마크다운)
├── 실습/                        # 강의 운영 메모 (목차·시간표·교육 철학)
└── AGENTS.md                    # 저장소 작업 규칙 (에이전트용)
```

## 주요 파일 설명

| 경로 | 설명 |
| :--- | :--- |
| `제조AI-교재/제조AI-교재-단일.md` | 교재 전문, 이미지가 파일 안에 내장되어 있어 어디서든 그대로 표시됨 |
| `제조AI-교재/제조AI-요약.md` | 장별 핵심 요약 — 수식·다이어그램·접이식 면접 질문 포함 |
| `제조AI-교재/스터디/` | 00 학습 로드맵부터 15 핵심 용어 사전까지 16개 학습 파일 |
| `제조AI-교재/용어정리/` | 시스템·표준·제어·데이터/AI·업무 5개 영역 용어 해설 |
| `제조AI-교재/원본자료/` | 교재 원본 docx와 삽입 이미지 (편집·재활용용) |
| `실습/` | 강의 개요, 12시간 시간표, 핵심 교육 철학 |
| `isa-95.html` / `isa-95.md` | ISA-95 계층구조만 따로 정리한 참고 문서 |

## 학습 가이드

1. `제조AI-교재/스터디/00 - 학습 로드맵.md` 부터 순서대로 읽습니다.
2. 각 스터디 파일은 `핵심 개념 → 다이어그램 → 실습 프롬프트(접힘) → 확인 문제(답 접힘) → 면접 포인트` 구성입니다.
3. 확인 문제는 답을 먼저 말하고 펼쳐서 맞춰보는 방식으로 활용합니다.
4. 용어가 막히면 `용어정리/` 폴더의 해당 영역 파일을 참고합니다.

## 옵시디언에서 사용하기

```bash

```
