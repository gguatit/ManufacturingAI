# 13 - 시스템 통합과 자율생산

> [!info] 이 파일에서 배우는 것
> - 시스템 통합을 직렬 체인이 아니라 **사건 중심의 병렬 데이터 공유**로 이해한다
> - 감지→판단→실행→검증→복귀 폐루프를 설명한다
> - 자율생산 성숙도 5단계와 Human-in-the-loop의 의미

> [!tip] 30초 요약
> 자율생산은 "완전 무인화"가 아니라 승인된 목표·규칙·권한·안전범위 안에서 폐루프가 반복되는 운영이다.

## 1. 치수불량 증가 사건의 통합 대응

```mermaid
flowchart LR
    S1[1 이상 인지] --> S2[2 영향범위 격리] --> S3[3 기준 확인] --> S4[4 공정 추적] --> S5[5 설비 이력] --> S6[6 조치 결정] --> S7[7 실행] --> S8[8 효과 검증]
```

| 단계 | 필요 데이터 | 관련 시스템 | 사람/AI 역할 |
| :--- | :--- | :--- | :--- |
| 1 이상 인지 | 불량률·측정값·lot | QMS/MES | AI 이상요약, 품질담당 확인 |
| 2 영향범위 격리 | finished/material lot, inventory status | QMS/WMS | 담당자 격리 승인 |
| 3 기준 확인 | revision, inspection spec | PLM/QMS | 최신 기준 검증 |
| 4 공정 추적 | work order, equipment, parameters | MES/POP/PLC-DCS | AI 상관·패턴 탐색 |
| 5 설비 이력 | alarm, vibration, maintenance | CMMS/TSDB | 정비가설·점검 |
| 6 조치 결정 | 납기·재고·대체설비 | ERP/SCM/MES | 사람이 우선순위·승인 |
| 7 실행 | 재검/재작업/정비/조건조정 | QMS/MES/CMMS/Control | 권한 내 실행 |
| 8 효과 검증 | 다음 lot 품질·설비상태 | QMS/MES/TSDB | 성과확인, 필요시 복귀 |

> [!warning] 모든 시스템을 직렬로 연결하지 않는다
> ==정보는 병렬로 공유된다==. 사건(치수불량)을 중심으로 필요한 시스템만 골라 연결한다.

## 2. 자율생산 성숙도 5단계

| 단계 | 시스템 역할 | 사람 역할 |
| :--- | :--- | :--- |
| ① 수작업 중심 | 기록 보조 수준 | 대부분 판단·실행 |
| ② 디지털 기록 | 데이터 수집·이력 | 기록 확인·판단 |
| ③ 규칙 기반 자동화 | 정해진 로직으로 자동 실행 | 예외·승인·규칙관리 |
| ④ AI 판단 지원 | 예측·추천·원인후보 | 검증·승인·책임 |
| ⑤ 검증된 범위 자율운영 | 허용범위 내 자동 재계획/제어 | 목표·권한·안전경계·감사 |

> [!note] 자율생산의 정의
> 승인된 목표·규칙·권한·안전범위 안에서 감지 → 판단 → 실행 → 검증 → 복귀가 반복되는 운영이다. (Human-in-the-loop)

## 실습 프롬프트

> [!example]- 통합 개선안 설계 (클릭해서 펼치기)
> 한빛부품에서 치수 불량이 증가했습니다. PLM, ERP, SCM, MES, QMS, CMMS, WMS, POP, PLC/DCS, Sensor/Actuator를 필요한 범위에서 연결해 대응 흐름을 설계하세요. "문제/사건, 필요한 데이터, 관련 시스템, 담당자, AI 지원역할, 승인/검증사항"의 6~8단계 표로 작성하세요. 모든 시스템을 억지로 직렬로 연결하지 말고 정보가 병렬 공유될 수 있음을 반영하세요. AI는 데이터 없이 원인을 확정하거나 안전기능을 우회하지 않도록 하세요.

> [!example]- 개발직무 확장 — 통합 인터페이스 최소계약 (클릭해서 펼치기)
> ERP→MES 생산요청과 MES→ERP 생산실적의 "교육용 최소 인터페이스 계약"을 작성하세요. 각 방향에 대해 필수 식별키, 날짜/시간, 수량, revision, status, error_code, idempotency_key를 포함하고, 성공/실패 응답과 재처리 시 주의점을 설명하세요. 실제 제품 API라고 표현하지 마세요.

## 확인 문제

> [!question]- Q1. 치수불량 대응에서 "격리(2단계)"가 "원인 분석(4~5단계)"보다 먼저 오는 이유는?
> 원인을 모르는 상태에서도 불량 로트의 추가 유출을 막아야 피해가 커지지 않는다. 통제가 분석보다 우선이다.

> [!question]- Q2. "자율생산 = 사람이 필요 없는 공장"이라는 말의 오류는?
> 자율생산에서도 사람은 목표·권한·안전경계 설정과 예외 승인을 담당한다. 승인된 범위 안의 자동화일 뿐, 책임까지 자동화되는 것이 아니다.

> [!quote] 면접 질문
> "자율생산에서 Human-in-the-loop가 필요한 이유는?" → AI 판단의 한계, 안전·책임, 예외 상황의 승인 주체가 필요하기 때문.
