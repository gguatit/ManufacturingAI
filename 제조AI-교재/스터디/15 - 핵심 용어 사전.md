# 15 - 핵심 용어 사전

> [!info] 사용법
> 약어가 처음 나오면 **정식 명칭과 의미를 함께** 말하는 습관을 들인다. "기억할 질문"에 스스로 답할 수 있으면 그 용어는 끝난 것이다.
> 심화 해설(풀이·예시 포함): [[00 - 사용법과 목차]]

## 1. 시스템 용어

| 용어 | 정식 명칭 | 기억할 질문 |
| :--- | :--- | :--- |
| ERP | Enterprise Resource Planning | 주문·구매·재고·원가 등 회사 자원을 어떻게 관리하는가? |
| SCM | Supply Chain Management | 공급부터 납품까지 어떻게 연결·계획·조정하는가? |
| PLM | Product Lifecycle Management | 무엇을 어떤 설계·제품구조·판으로 만들 것인가? |
| MES | Manufacturing Execution System | 현장에서 무엇을 언제 어떻게 생산하고 있는가? |
| MOM | Manufacturing Operations Management | 생산·품질·정비·재고 등 제조운영활동을 어떻게 관리하는가? |
| POP | Point of Production (국내 현장정보 수집 의미) | 작업·실적·정지 정보를 현장에서 어떻게 수집하는가? |
| QMS | Quality Management System | 품질기준을 지키고 부적합·원인·재발을 어떻게 관리하는가? |
| CMMS | Computerized Maintenance Management System | 설비를 언제 어떻게 정비하고 이력을 남길 것인가? |
| WMS | Warehouse Management System | 자재·제품이 어디에 어떤 상태로 있고 누구에게 예약됐는가? |

## 2. 제어·데이터 용어

| 용어 | 정식 명칭 | 기억할 질문 |
| :--- | :--- | :--- |
| PLC | Programmable Logic Controller | 기계·라인의 로직과 동작을 어떻게 제어하는가? |
| DCS | Distributed Control System | 여러 제어루프와 운전·감시를 어떻게 통합하는가? |
| Sensor | 센서 | 현재 온도·압력·위치·진동 등 상태가 어떠한가? |
| Actuator | 구동기 | 밸브·모터·실린더 등을 어떻게 움직이는가? |
| RDB | Relational Database | 주문·작업지시·검사 같은 관계형 업무데이터 저장 |
| TSDB | Time Series Database | 시간에 따라 발생하는 센서·상태 데이터 저장 |
| RAG | Retrieval-Augmented Generation | 표준서·매뉴얼 등 근거문서를 찾아 AI 답변에 연결 |

## 3. 업무 개념 용어

| 용어 | 의미 | 기억할 질문 |
| :--- | :--- | :--- |
| ATP | Available-to-Promise, 납기약속가능수량 | 현재 정보로 고객 주문에 약속 가능한 수량/납기를 어떻게 판단하는가? |
| Traceability | 추적성 | 제품이 어떤 자재·작업·설비·조건·검사를 거쳤는지 찾을 수 있는가? |
| MTTR | Mean Time To Repair, 평균 수리 시간 | 고장 후 복구까지 평균 얼마나 걸리는가? |
| %p | 퍼센트 포인트 | 4.67%→2.33%는 2.34%p 감소 (상대 감소율 약 50%와 구분) |

## 확인 문제

> [!question]- Q1. 다음 약어의 정식 명칭을 말해보세요: MES, QMS, CMMS, WMS
> MES = Manufacturing Execution System / QMS = Quality Management System / CMMS = Computerized Maintenance Management System / WMS = Warehouse Management System

> [!question]- Q2. MOM과 MES의 관계는?
> MOM(제조운영관리)은 생산·품질·정비·재고 운영활동 전체를 아우르는 개념이고, MES는 그중 생산 실행을 지원하는 대표 시스템이다. ISA-95에서는 Level 3를 MOM으로 총칭한다.

> [!question]- Q3. RDB와 TSDB에 각각 저장할 데이터를 한빛부품 예로 들면?
> RDB: 주문·작업지시·자재로트·검사·정비 (업무 트랜잭션) / TSDB: 온도·진동·유량·설비상태 (시간축 센서 데이터)

> [!quote] 마무리
> 용어는 목적이 아니라 도구다. "이 용어가 어떤 업무 질문에 답하는가"로 기억하면 면접에서 자연스럽게 나온다.
