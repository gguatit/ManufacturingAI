# 01 - 실습 방법과 AI 검증

> [!info] 이 파일에서 배우는 것
> - AI를 "정답 제공기"가 아니라 사고 확장 도구로 쓰는 방법
> - 프롬프트 5요소와 AI 답변 검토 6문항
> - 수업 공통 시스템 지시문 (그대로 복사해서 사용)

> [!tip] 30초 요약
> AI에게 먼저 묻지 말고 **내 예상 답을 먼저 적고**, AI 답변과 비교해 빠진 조건과 근거 없는 가정을 찾아낸다.

## 1. 수업 진행 방식

학생 예상답 → AI 질의 → 강사 검토 → 문서화(Word/노트)

AI는 답을 대신 만드는 도구가 아니다. 이 과정을 반복하면 "AI에 의존하는 사람"이 아니라 "AI 결과를 검토할 수 있는 제조업무 이해자"가 된다.

## 2. 프롬프트 5요소

| 요소 | 질문에 넣을 내용 | 한빛부품 예시 |
| :--- | :--- | :--- |
| 목적 | 무엇을 판단하거나 만들 것인가 | 납기 확정에 필요한 정보를 정리 |
| 상황/맥락 | 공정·문제·현재 데이터 | 주문 1,000개, 재고 1,200개, 품질보류 200개 |
| 제공자료 | 표·수치·규칙·정의 | 보류와 예약은 중복되지 않음 |
| 제약 | 하지 말아야 할 추정·범위 | 납품일을 임의로 정하지 말 것 |
| 출력형식 | 표, 단계, 필드, 체크리스트 | 계산 → 추가정보 → ERP/SCM 비교 표 |

## 3. AI 답변 검토 6문항

1. 개념이 정확한가? — ISA-95 Level 3을 MES 제품 하나와 동일시하지 않았는가?
2. 한빛부품 사례에 맞는가? — 다른 산업의 공정을 끌어오지 않았는가?
3. 제공되지 않은 사실·수치·성과를 만들지 않았는가?
4. 판단에 필요한 정보가 빠지지 않았는가? — 제품, 로트, 설비, 시간, 도면판, 상태
5. 확인된 사실과 원인 가설을 구분했는가?
6. 자신의 말로 설명할 수 있을 만큼 단순하고 구조화되어 있는가?

## 4. 공통 시스템 지시문 (복사해서 사용)

> [!example]- 공통 시스템 지시문 — 필요할 때 펼쳐서 복사
> 당신은 제조기업 취업준비생의 학습을 돕는 스마트제조 교육 보조자입니다. 대상 학생은 제조업 경험이 많지 않습니다. 가상의 한빛부품을 예로 설명하세요. 공정은 자재 입고→가공→세척→열처리→검사→포장→출하입니다.
> 답변 규칙: 1) 첫 문장은 쉬운 설명으로 시작합니다. 2) 약어가 처음 나오면 정식 명칭과 의미를 함께 설명합니다. 3) ISA-95의 활동 계층과 ERP/MES 같은 소프트웨어 제품명을 혼동하지 않습니다. 4) 표준 개념, 수업용 가정, 회사별 구현 차이를 구분합니다. 5) 제공되지 않은 수치나 실제 기업 성과를 만들지 않습니다. 6) AI 제안을 확정된 원인이나 검증된 개선성과로 표현하지 않습니다. 7) 사실/가정/원인 가설/추가 확인사항을 구분합니다. 8) 출력은 짧은 설명 + 표 중심으로 작성합니다. 9) 마지막에 학생 확인 질문 1개를 제시합니다. 10) 실제 기업의 비공개 데이터나 안전제어 코드는 요구하지 않습니다.

## 5. AI 답변을 학습문서로 바꾸는 방법

| AI 원문 | 학생이 해야 할 일 | 노트에 남길 결과 |
| :--- | :--- | :--- |
| 설명 10문단 | 핵심 문장 3개로 축약 | 정의·원칙 |
| 표 20행 | 한빛부품에 필요한 행만 선택 | 사례표 |
| 원인 6개 제안 | 사실/가설 분리, 필요한 데이터 추가 | 원인검증 체크리스트 |
| 효과 수치 제시 | 출처·기준선 없으면 삭제 | 측정할 KPI만 기록 |
| 구현 제안 | 담당자·승인·안전·권한 확인 | 실행·검증 흐름 |

> [!warning] 보안 원칙
> 수업에서는 가상의 한빛부품 데이터만 사용한다. 실제 기업의 도면, 고객정보, 개인정보, 비공개 설비조건, 내부 원가나 생산데이터는 공개형 생성형 AI에 입력하지 않는다.

## 확인 문제

> [!question]- Q1. AI가 "3일 후 납품 가능합니다"라고 답했다. 그대로 쓰면 안 되는 이유와 처리 방법은?
> 기준선·출처 없는 날짜는 근거가 없다(검토 3번). 해당 문장을 삭제하고, 납기를 확정하기 위해 필요한 정보 목록(공급일, 설비 가용시간, 리드타임 등)으로 바꾼다.

> [!question]- Q2. AI 답변이 그럴듯할 때 가장 먼저 확인할 두 가지는?
> ① 개념 정확성 (예: ISA-95 Level 3을 MES 제품 하나로 동일시했는지) ② 제공 데이터에 없는 수치·성과를 만들었는지.

> [!quote] 면접 포인트
> "AI가 이렇게 답했습니다"보다 "AI 답변 중 근거 없는 부분을 제거하고, 추가 데이터가 필요한 부분을 이렇게 수정했습니다"가 훨씬 강한 답이다.
