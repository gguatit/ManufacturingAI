# 06 - PLM

> [!info] 이 파일에서 배우는 것
> - PLM을 도면 저장소가 아니라 제품구조·Revision·변경·적용범위 관리로 이해한다
> - A판→B판 변경이 구매·재고·생산·검사에 미치는 영향 분석
> - 기존 자재·재공품을 자동 폐기하지 않고 승인된 처리를 거치는 원칙

> [!tip] 30초 요약
> 설계변경은 새 도면 배포로 끝나지 않는다. **승인·적용범위(Effectivity)·기존 자재 처리·생산지시·검사기준**이 함께 바뀌어야 한다.

## 1. PLM에서 구분할 네 가지

| 개념 | 학생용 설명 | 한빛부품 질문 |
| :--- | :--- | :--- |
| Revision | 도면/설계의 유효한 판 | 현재 생산에 유효한 A/B판은 무엇인가? |
| BOM | 무엇으로 구성되는가 | 새 소재규격이 어떤 부품에 연결되는가? |
| Routing/BOP | 어떤 공정으로 만드는가 | 변경으로 공정·작업방법이 달라지는가? |
| Effectivity | 언제/어느 로트부터 적용하는가 | B판은 어떤 주문·로트부터 적용하는가? |

## 2. A→B판 변경의 전파

| 시스템 | 반영할 것 |
| :--- | :--- |
| PLM | 변경사유·승인·Revision·Effectivity 관리 |
| ERP/SCM | 구매규격·기존 발주·재고 영향 검토 |
| MES | 적용 로트와 작업지시/공정조건 반영 |
| QMS | 검사규격·공차·판정기준 반영 |

**기존 자재·재공품 처리**: 사용 / 특채 / 재작업 / 반품 / 폐기 — 반드시 **승인된 처리**를 선택한다. 자동 폐기 금지.

## 실습 프롬프트

> [!example]- A판에서 B판 변경 영향분석 (클릭해서 펼치기)
> 한빛부품 제품 도면이 A판에서 B판으로 변경되었습니다. 일부 치수와 소재 규격이 바뀌었지만 현장에는 A판이 남아 있고, 이미 구매한 소재와 생산 중인 제품도 있습니다. PLM이 관리해야 할 정보와 ERP·SCM·MES·QMS에 전달해야 할 정보를 정리하세요. 설계변경 내용, 승인, 적용 시점/대상 로트, 기존 자재·재공품 처리, 작업지시, 검사기준 변경을 포함한 표를 작성하세요. 적용 시점이 제공되지 않았으므로 임의로 결정하지 마세요.

> [!example]- 개발직무 확장 — 변경영향 데이터 필드 (클릭해서 펼치기)
> 설계변경 영향추적을 위한 교육용 데이터 필드를 제안하세요. engineering_change_id, old_revision, new_revision, affected_item, effectivity_type, effectivity_value, approval_status, affected_order, affected_lot, disposition을 포함하세요. 필드별 설명과 데이터 관계를 표로 정리하세요. 실제 PLM 제품의 스키마라고 단정하지 마세요.

## 확인 문제

> [!question]- Q1. Revision과 Effectivity의 차이는?
> Revision은 "어떤 판인가"(설계 자체), Effectivity는 "언제부터/어느 로트부터 그 판을 적용하는가"(적용 범위)다.

> [!question]- Q2. 현장에 A판 자재가 남아 있을 때 "폐기"를 먼저 결정하면 왜 안 되는가?
> 사용·특채·재작업·반품 등 다른 선택지가 남아 있고, 처리 선택은 승인 절차(품질·원가·납기 영향)를 거쳐야 하기 때문이다.

> [!quote] 면접 한 문장
> "설계변경은 새 도면을 배포하는 것으로 끝나지 않고, 승인·적용범위·기존 자재/재공품 처리·생산지시·검사기준이 함께 변경되어야 합니다."
