# 05 - ERP와 SCM

> [!info] 이 파일에서 배우는 것
> - ERP(내부 자원관리)와 SCM(공급망 조정)의 구분
> - 전산재고와 사용가능재고의 차이
> - ATP(Available-to-Promise) 계산과 "계산만으로 납기를 확정하면 안 되는 이유"

> [!tip] 30초 요약
> 재고가 있어도 납기를 약속할 수 없다. 품질보류·예약을 뺀 **사용가능재고**에 공급·생산능력·리드타임·검사·운송 조건까지 확인해야 납기가 확정된다.

## 1. ERP vs SCM

| 구분 | ERP | SCM |
| :--- | :--- | :--- |
| 초점 | 내부 자원 관리 | 공급망 계획·조정 |
| 대표 질문 | 주문·구매·재고·원가를 어떻게 관리하는가 | 공급부터 납품까지 어떻게 연결·조정하는가 |
| 한빛부품 예 | 수주 등록, 재고·구매·원가 | 자재 공급 일정, 납기 조정 |

## 2. ERP Mini의 최소 데이터

| 데이터 객체 | 핵심 필드 | 왜 필요한가 |
| :--- | :--- | :--- |
| Item | item_id, item_name | 주문과 재고의 품목 기준 |
| Inventory | on_hand, quality_hold, reserved | 실물·보류·예약을 분리 |
| Sales Order | order_id, item_id, qty, due_date, status | 고객 요구와 납기 기준 |
| Purchase/Supply | expected_qty, expected_date | 부족분 보충 가능성 |
| Production Request | request_id, order_id, qty, status | ERP→MES 제조요청 연결 |

## 3. 사용가능재고와 ATP 계산

**전산재고 ≠ 사용가능재고**

$$
\text{사용가능} = \text{on\_hand} - \text{quality\_hold} - \text{reserved}
$$

**수업 데이터 계산** (수업용 가정: 보류와 예약은 중복되지 않음)

$$
\text{사용가능} = 1{,}200 - 200 - 100 = 900 \qquad \text{부족} = 1{,}000 - 900 = 100
$$

> [!warning] 계산만으로 납품일을 확정하면 안 된다
> 추가 공급일, 생산설비 가용시간, 공정 리드타임, 검사, 포장, 운송 조건이 더 필요하다. AI가 "3일 후 납품 가능" 같은 날짜를 만들면 삭제한다.

## 실습 프롬프트

> [!example]- 납기 확정 질문 설계 (클릭해서 펼치기)
> 한빛부품에 제품 1,000개 주문이 들어왔습니다. 제품 하나당 소재 하나가 필요합니다. 전산 소재는 1,200개이며, 품질보류 200개와 다른 주문 예약 100개는 서로 중복되지 않습니다. 추가 소재의 공급일은 확정되지 않았고 생산설비 가용시간도 확인해야 합니다. 1) 현재 사용할 수 있는 소재와 부족 수량을 계산하세요. 2) 납기를 확정하기 위해 추가로 필요한 정보를 8개 이내로 제시하세요. 3) ERP와 SCM이 관리/조정하는 정보를 비교하세요. 4) 정보가 부족한 상태에서 납품 가능일을 임의로 정하지 마세요.

> [!example]- 개발직무 확장 — 생산요청 JSON (클릭해서 펼치기)
> ERP가 MES에 생산요청을 전달하는 교육용 JSON 예시를 만들어 주세요. 필드는 request_id, order_id, item_id, qty, requested_due_date, priority, revision, status만 사용하세요. 각 필드가 왜 필요한지 표로 설명하고, 실제 기업에서는 인터페이스 표준·보안·오류처리가 추가로 필요하다고 명시하세요.

> [!info]- 학생 검산
> 사용가능 소재 900개, 부족 100개가 나와야 한다.

## 확인 문제

> [!question]- Q1. 부록 B-1 데이터로 HB-200의 사용가능 재고를 계산하면? (on_hand 450, quality_hold 50, reserved 80, 주문 300)
> 450 − 50 − 80 = **320개**. 주문 300개는 충족되지만, 납기 확정은 공급일(2026-09-22)·설비 가용시간 확인 후에 가능하다.

> [!question]- Q2. "재고가 충분한데도 납기를 약속할 수 없는 이유"를 3가지 이상 말하면?
> ① 품질보류·예약 제외하면 실제 가용 수량이 다름 ② 공급·생산능력·리드타임 미확인 ③ 검사·포장·운송 조건 미확인.

> [!quote] 면접 포인트
> ERP는 "내부 자원", SCM은 "공급망 조정"이라는 구분을 실제 업무 예시와 함께 말할 수 있어야 한다.
