2. 한빛부품 일곱 문제 우선순위 - 실습 답안

[실습 프롬프트 (교재 2.3)]
한빛부품의 일곱 문제 중 하나만 먼저 해결한다면 무엇을 선택해야 할까요?
선택 이유 2개, 판단에 필요한 데이터 4개, 관련 담당자 3명을 표로 작성하세요.
정확한 효과 수치가 주어지지 않았으므로 개선율은 만들지 마세요.
마지막에 "추가로 확인할 정보"를 3개 제시하세요.

[답안]

고객이 "제품 1,000개를 언제 받을 수 있나요?"라고 물었을 때 바로 답하려면, 재고·생산·자재 정보가 한 흐름으로 연결되어 있어야 합니다. 일곱 문제 중 저는 '납기 확인 지연'을 먼저 해결할 문제로 선택했습니다. 정답은 하나가 아니며, 아래는 선택 예시입니다. (교재 강사 해설)

ISA-95(전사 시스템과 제조 시스템 간 정보 교환 국제표준, IEC 62264) 관점에서 보면, 이 문제는 Level 4(사업계획: 주문·납기)의 정보와 Level 3(제조운영: 재고·생산)의 정보가 연결되지 않은 상태입니다.

■ 선택 이유 2개

| 선택 이유 | 설명 |
| --- | --- |
| 1. 고객 접점의 첫 관문 | 주문이 들어오면 납기 회신이 가장 먼저 필요합니다. 2.2 시나리오도 월요일 9시 고객 질문에서 시작합니다. |
| 2. 다른 문제의 선행 기반 | 납기에 답하려면 가용재고·생산진척·자재 정보를 연결해야 하므로, '종이 실적'·'재고 활용 곤란' 문제의 데이터 연결 작업이 함께 진행됩니다. |

■ 판단에 필요한 데이터 4개 / 관련 담당자 3명

| 구분 | 항목 | 왜 필요한가 |
| --- | --- | --- |
| 데이터 | 제품별 가용재고(위치·품질보류·타 주문 예약 제외 수량) | 전산 수량과 실제 출고 가능 수량이 다르기 때문 |
| 데이터 | 진행 중 작업지시 잔량과 예상 완료일 | 재고가 부족할 때 언제 채워지는지 계산 |
| 데이터 | 자재 가용량과 구매 입고 예정일 | 자재가 없으면 생산 일정이 무의미 |
| 데이터 | 설비 가동 가능 능력(정비 계획·비가동 반영) | 설비 정지 같은 변동이 납기를 바꿈 |
| 담당자 | 영업 | 고객 희망납기·분납 가능 여부 확인 |
| 담당자 | 생산관리 | 부하·일정 확정, 어제 실적 파악 |
| 담당자 | 자재/구매 | 입고 예정 확인, 부족 시 대안 검토 |

■ 사실 / 가정 / 원인 가설 / 추가 확인 구분

| 구분 | 내용 |
| --- | --- |
| 확인된 사실(시나리오) | 영업이 위치·품질보류·예약 여부를 즉시 알 수 없음 / 실적은 전화·종이로 확인 / 오후 설비 정지 후 엑셀 재작업 |
| 수업용 가정 | 품질보류 200개와 타 주문 예약 100개는 서로 중복되지 않음 (교재 모듈 3 ATP 조건) |
| 원인 가설(미확정) | 재고 수량은 ERP(Enterprise Resource Planning, 전사자원관리)에 있어도 위치·품질상태·예약 정보가 WMS(Warehouse Management System, 창고관리시스템)·QMS(Quality Management System, 품질관리시스템)와 연결되지 않아 회신이 늦어질 수 있음 |
| 회사별 차이 | 가용재고에서 무엇을 제외하는지(보류·예약·검사중)는 회사마다 다름 — 위 정의는 수업 기준 |

■ 추가로 확인할 정보 3개

1. 현재 납기 응답 소요시간과 납기 준수율의 실측 기준선
2. 가용재고 계산 규칙(예약·품질보류 제외 기준)의 문서화 여부
3. 고객의 희망납기와 분납 수용 가능 여부

※ 제공된 수치가 없어 개선율은 작성하지 않았습니다. 위 내용은 검증된 성과가 아니라 학습용 판단 예시입니다.
